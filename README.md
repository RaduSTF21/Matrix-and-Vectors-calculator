# Matrix and Vectors Calculator

A C++ desktop calculator for practicing vector and matrix operations through an interactive graphical interface.

## Features

- Vector arithmetic and element-wise operations
- Matrix arithmetic
- Determinants, powers, inverse, and transpose
- Diagonal sums and products
- Vector sorting algorithms, including bubble sort and merge sort
- Random and user-provided data

## Technology

- C++
- WinBGIm / `graphics.h`

The project was created as an introductory programming exercise and demonstrates menu-driven graphics, data structures, and numerical algorithms.
